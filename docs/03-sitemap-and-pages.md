# 03 — Sitemap and Page Jobs

Each page has one job. Navigation labels use plain words.

## Primary navigation
About · Our Work · Get Involved · Stories · Events · Give (persistent, visually distinct button)

## Pages
| Page | Job | Key modules |
|---|---|---|
| **Home** | State who we are and why now; route to action | Signature hero moment, mission statement, live impact, featured story, current campaign, ways to act, newsletter, trust strip |
| **About** | Build belief and trust | Origin story, mission/vision/values, timeline, leadership, board, partners, FAQ |
| **Our Work** | Show what we do | Program index; each program page: problem, approach, results, how to help, related stories |
| **Impact** | Prove it | Verified metrics with sources and dates, map, annual reports, methodology note |
| **Stories** | Make it human | Filterable story/news archive; story template with pull quotes, media, related actions |
| **Get Involved** | Hub for action | Volunteer, join, partner, fundraise for us, advocate, careers; each with its own form |
| **Donate** | Convert with confidence | Amount picker, one-time/monthly, impact equivalents, payment methods, security cues, tribute gifts, receipt info, FAQ |
| **Campaigns** | Time-bound pushes | Campaign template with progress, deadline, updates, share tools |
| **Events** | Fill rooms and calendars | Calendar and list, event detail, registration, add-to-calendar, past-event recaps |
| **Take Action** | Advocacy | Petition template, signature count, share, representative lookup (if applicable) |
| **Resources** | Utility and credibility | Downloads, reports, toolkits |
| **Press** | Serve journalists | Releases, media contacts, logos, photos, fact sheet |
| **Transparency** | Earn trust | Governance, financials, policies, audits, how donations are used |
| **Contact** | Easy reach | Form, address, map, social, accessibility contact |
| **Legal** | Compliance | Privacy, terms, cookies, accessibility statement, donation policy |
| **404 / Error / Thank-you** | Keep momentum | Designed states, each with a next action |
| **Search** | Findability | Site-wide search |

## Cross-site elements
- Header with Give button; footer with newsletter, registration details, social, legal links
- Language switcher (if multilingual)
- Consent banner only if required by region and analytics used
- CMS-controlled announcement banner
